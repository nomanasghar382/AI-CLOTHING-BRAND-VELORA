# Supplier Manual

## Profile

1. Sign in with a supplier account
2. Complete company profile with contact details and tax ID
3. Add warehouse addresses

## Inventory

- View synced inventory levels per product
- Sync inventory from your systems
- Adjust stock with audit trail
- Reserve inventory for pending orders

## Operations

- Manage purchase orders, shipments, and returns
- Upload certifications and compliance documents
- Review performance metrics and settlements

## API Access

- Generate API tokens for inventory sync integrations
- Configure webhooks for order and shipment events

## Certifications

- Upload supplier certifications for ethical passport verification
- Track certification status and expiry

## Portal Navigation

Access the supplier portal at `/supplier` for inventory, orders, and performance dashboards.
