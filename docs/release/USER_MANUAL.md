# User Manual

VELORA is a modest fashion commerce platform with AI styling, creator commerce, community features, and enterprise operations tooling.

## Account Types

| Role | Capabilities |
|------|-------------|
| Customer | Shop, style AI, wardrobe, loyalty, community |
| Creator | Collections, lookboards, commissions, followers |
| Supplier | Inventory, fulfillment, certifications |
| Admin | Full platform operations and analytics |

## Key Features

- **Catalog** — 1000+ products with advanced filters and instant search
- **Shopping** — Cart, wishlist, checkout, payments, returns
- **AI Fashion Engine** — Style quiz, recommendations, chat, trends
- **Wardrobe** — Digital closet with AI recommendations
- **Visual Search** — Image-based product discovery
- **Community** — Posts, likes, comments, bookmarks
- **Loyalty** — Points, VIP tiers, rewards, referrals, gift cards
- **Ethical Passport** — Verified sustainability claims per product
- **International** — Multi-currency, regional shipping, duty rules
- **PWA** — Installable app with offline support

## Getting Help

- Use the support ticket system from your account
- Contact admin via the support desk for order issues
- Review role-specific manuals for detailed workflows

## Privacy & Security

- Passwords are hashed with bcrypt
- API tokens managed via Laravel Sanctum
- Payment data handled by Stripe (PCI compliant)
- No secrets exposed to the browser
