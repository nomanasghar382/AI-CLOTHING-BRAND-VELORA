# Admin Manual

## Access

Sign in at `/admin` with an admin or super-admin account.

## Command Center

The dashboard shows revenue, orders, catalog metrics, and recent orders. Quick actions and pinned dashboards provide fast navigation.

## Command Palette

Press `⌘K` (Mac) or `Ctrl+K` (Windows/Linux) to open the command palette:

- Search products, orders, customers, creators, suppliers, community posts, and support tickets
- Navigate to any admin section
- Run quick actions like cache clearing

## Product Management

- View and filter the product catalog
- Create and edit products with categories, pricing, and stock
- Export product data to CSV

## Order Management

- Review order pipeline by status
- Transition order statuses
- Manage payments, captures, and refunds
- Process return requests

## Analytics & Reports

- View revenue and order analytics
- Export order, customer, and product reports as CSV
- Review trend forecasting signals

## Operations

- Monitor system health (database, cache, queue, memory)
- View queue status and scheduler runs
- Manage feature flags
- Run and review backups
- Review audit logs and security events

## Support

- Manage support tickets and reply to customers
- Assign ticket priority and status

## Settings

- Configure store settings
- Manage shipping methods, tax rules, and international commerce

## Demo Mode

When `VELORA_DEMO_MODE=true`, the platform is pre-populated with realistic demo data for presentations and QA.
