# Creator Manual

## Profile Setup

1. Sign in with a creator account
2. Navigate to the creator portal
3. Set your handle, display name, bio, and social links
4. Enable commission acceptance if desired

## Collections

- Create curated product collections
- Add published catalog products to collections
- Share collections with followers

## Lookboards

- Create visual lookboards with product placements
- Set cover images and descriptions
- Choose public or private visibility

## Earnings

- View commission balance and transaction history
- Request withdrawals when balance meets minimum threshold

## Followers

- Customers can follow your creator profile
- Build audience through community posts and collections

## Media

- Upload images via Cloudinary integration (requires server configuration)
- Use uploaded media in community posts and lookboards

## Wardrobe Integration

- Manage your personal wardrobe items
- Get product recommendations based on owned pieces
