# VELORA Creator Guide

See [docs/release/CREATOR_MANUAL.md](release/CREATOR_MANUAL.md) for complete documentation.

## Profile Setup

1. Sign in with a creator account (`creator@velora.test` / `VeloraDemo!2026`)
2. Set your handle, display name, bio, and social links
3. Enable commission acceptance if desired

## Collections

- Create curated product collections
- Add published catalog products
- Share collections with followers

## Lookboards

- Create visual lookboards with product placements
- Set cover images and public/private visibility

## Earnings

- View commission balance and transaction history
- Request withdrawals when balance meets minimum threshold

## Community

- Share outfit posts and styling thoughts
- Engage with the community feed
