## Description (LinkedIn Project Section)

VELORA is a production-grade, full-stack modest fashion commerce platform I designed and built as my capstone project. It combines AI-powered personal styling with complete e-commerce, creator commerce, community engagement, and enterprise administration.

**What I built:**

🛍️ Full e-commerce platform — catalog, cart, checkout (Stripe), orders, returns, international shipping with multi-currency support

🤖 AI Fashion Engine — style profile quiz, catalog-grounded outfit recommendations, occasion stylist, conversational AI chat, visual search, and digital wardrobe — all powered by OpenAI (server-side only)

👥 Creator & Community — creator collections, lookboards, commission tracking, social feed with moderation

🌍 International Commerce — shipping estimates, duty calculation, regional size guides, currency conversion

♻️ Ethical Fashion Passport — verified sustainability claims with evidence documentation

🎁 Loyalty Platform — points wallet, VIP tiers, referrals, gift cards, product alerts

🏭 Supplier Portal — inventory management, purchase orders, settlements, webhook sync

📊 Enterprise Admin — command palette (⌘K), global search, BI analytics, AI trend forecasting, operations center

**Technical stack:** React 19, Vite, Bootstrap 5, PWA, Laravel 12, Sanctum, MySQL (144 tables), Redis, Stripe, Cloudinary, OpenAI, Docker, GitHub Actions

**By the numbers:** 198 API endpoints · 101 models · 27 services · 51 automated tests · 45+ documentation guides

**Security:** Sanctum authentication, RBAC, audit logging, webhook verification, secrets isolated server-side
