## Repository Description (Full)

VELORA is a production-ready, AI-powered global modest fashion commerce platform built with React 19 and Laravel 12.

**Features:** Product catalog, shopping cart, Stripe checkout, AI style profile, occasion stylist, outfit builder, visual search, digital wardrobe, creator commerce, community platform, international commerce, ethical fashion passport, loyalty program, supplier portal, enterprise admin with BI analytics, and PWA support.

**Stack:** React 19 · Vite · Bootstrap 5 · Laravel 12 · Sanctum · MySQL 8 · Redis · Stripe · Cloudinary · OpenAI · Docker · GitHub Actions

**Stats:** 144 tables · 198 API endpoints · 101 models · 51 tests · 45+ docs
